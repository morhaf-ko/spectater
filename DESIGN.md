# Review interface

The operator selected a document reader with artifact navigation, a central document and a feedback sidebar. This Read/Operate surface prioritizes source comprehension and explicit feedback state.

Use system sans for controls, Georgia for rendered prose and monospace for source, hashes and retrieval commands. Use a light paper surface, dark ink and restrained teal actions. Separate navigation and feedback with single rules; avoid decorative cards. No external fonts or assets.

Tokens: paper #faf9f6, panel #f1f0eb, ink #202725, muted #535e59, rule #ceD3cd, action #155d4c, error #943c2f. Body 17px/1.65; controls 14px; document measure 72ch. Spacing follows 4/8/12/16/24/32px.

Desktop has three columns: 220px navigation, flexible reading area and 310px feedback. Below 1100px feedback follows the document; below 700px all regions stack. Keep focus visible, label all controls, announce errors and receipts, preserve drafts on refresh/conflict and respect reduced motion. Status words accompany color. No automatic animation or theme switching.
